# SkillSwap AI

A phone-friendly prototype for a student skill-exchange community.

## Run it
Open `index.html` in a browser, or enable GitHub Pages in the repository settings to publish it.

## Demo features
- Discover sample student profiles and filter by skill/category.
- Create a local skill profile.
- Send sample swap requests.
- View a demo skill-credit balance.

## Prototype limits
This is a front-end demonstration. It has no real accounts, server, cross-device sync, live AI matching, chat, or verified student identities. Profiles and requests are saved only in the browser on the current device. Match percentages and credits are illustrative.

## Responsible rollout
For a real school launch, use school-approved accounts, teacher moderation, minimal personal data, and supervised ways to arrange learning sessions. Do not publish students' phone numbers or home addresses.

## Business and impact
A school or learning club could pay for a moderated institution version or sponsored skill events. The social impact is peer learning with fewer money barriers and better use of students' existing skills.
